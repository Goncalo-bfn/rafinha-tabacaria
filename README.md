# Rafinha Tabacaria

Página pública reconstruída a partir dos arquivos de referência do Lovable.

## Requisitos

- Node.js 20.19+ ou 22.12+
- npm

## Executar

```sh
npm install
npm run dev
```

## Validar e gerar build

```sh
npm run build
npm run preview
```

O telefone e as informações de contato ficam centralizados em `src/config/store.ts`.
Os seis produtos permanecem placeholders em `src/data/products.ts`.
